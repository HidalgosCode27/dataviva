Formulario de jefes de turno

Un parte de turno en Streamlit que se guarda en SQLite. La arquitectura son tres módulos: app.py, validar.py y storage.py.

  • Python
  • Streamlit
  • SQLite

Contexto

En el almacén, cada jefe de turno deja un parte. El formulario pone esa nota en campos, en vez de un mensaje suelto. No uso nombres de personas: en los ejemplos el jefe se llama «Jefe ejemplo».

[Pendiente: campos definitivos del parte y quién lo pidió]

Problema

Un parte repetido ensucia el histórico. La regla de duplicado es concreta: misma fecha, mismo jefe de turno y mismo turno.

[Pendiente: qué fallaba en el proceso anterior]

Qué hice

Organicé la app en tres piezas. La interfaz no decide sola si el parte es nuevo: le pregunta a la validación y, si pasa, se lo entrega al almacenamiento.

  1. app.py La pantalla del formulario en Streamlit: fecha, jefe de turno, turno y nota.
  2. validar.py Las reglas. Hay duplicado si coinciden fecha, jefe y turno.
  3. storage.py Lee y escribe el parte en SQLite.

Datos de ejemplo. La maqueta no envía nada y los fragmentos no son el código fuente real: ilustran la arquitectura.

app.pyDatos de ejemplo
import streamlit as st
from validar import es_duplicado
from storage import guardar, leer

st.title("Parte de turno")

parte = {
    "fecha": str(st.date_input("Fecha")),
    "jefe": st.text_input("Jefe de turno"),
    "turno": st.selectbox("Turno", ["Mañana", "Tarde", "Noche"]),
    "nota": st.text_area("Nota"),
}

if st.button("Guardar"):
    if es_duplicado(parte, leer()):
        st.error("Ya existe un parte con esa fecha, ese jefe y ese turno.")
    else:
        guardar(parte)
        st.success("Parte guardado.")
validar.pyDatos de ejemplo
CLAVE = ("fecha", "jefe", "turno")

def es_duplicado(parte, existentes):
    clave = tuple(parte[campo] for campo in CLAVE)
    for previo in existentes:
        if tuple(previo[campo] for campo in CLAVE) == clave:
            return True
    return False
storage.pyDatos de ejemplo
import sqlite3

def guardar(parte):
    with sqlite3.connect("partes.db") as con:
        con.execute(
            """
            INSERT INTO partes (fecha, jefe, turno, nota)
            VALUES (:fecha, :jefe, :turno, :nota)
            """,
            parte,
        )

Si entra otro parte con fecha 2024-03-12, jefe «Jefe ejemplo» y turno Mañana, es_duplicado devuelve verdadero y no se guarda. Cambia la fecha, el jefe o el turno, y ya no es el mismo parte.
