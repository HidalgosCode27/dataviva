Conciliación de stock

Cruzar el stock que ve el cliente con el stock del WMS. Un FULL OUTER JOIN en SQL, y el mismo cruce en pandas, para no perder las filas que viven en un solo lado.

  • SQL
  • PostgreSQL
  • Python
  • pandas

Contexto

En el almacén de Sagunto hay dos listas del mismo stock: la del sistema del cliente y la del WMS. El caso es conciliarlas. No nombro sistemas comerciales, clientes ni personas.

[Pendiente: cada cuánto se conciliaba y quién leía el resultado]

Problema

Un INNER JOIN deja fuera el SKU que está solo en un lado. Ese es justo el descuadre que la conciliación tiene que ver: unidades que no coinciden y referencias que faltan en uno de los dos sistemas.

[Pendiente: qué se hacía con las diferencias]

Qué hice

Propuse el cruce con un FULL OUTER JOIN y el equivalente en pandas (merge con how="outer"). La diferencia de ejemplo es unidades del cliente menos unidades del WMS. Si un lado no tiene el SKU, cuenta como cero solo para esa resta.

La sintaxis de SQL es la de PostgreSQL. No afirmo con esto que la base del almacén sea PostgreSQL: [Pendiente: motor real de la consulta].

Datos de ejemplo. SKU y unidades inventados. No son stock de un cliente ni de un WMS.

conciliacion.sqlDatos de ejemplo
-- Datos de ejemplo. No es un esquema real.
WITH cliente AS (
  SELECT * FROM (VALUES
    ('SKU-101', 120),
    ('SKU-204', 40),
    ('SKU-318', 15)
  ) AS t(sku, unidades)
),
wms AS (
  SELECT * FROM (VALUES
    ('SKU-101', 118),
    ('SKU-204', 40),
    ('SKU-422', 7)
  ) AS t(sku, unidades)
)
SELECT
  COALESCE(c.sku, w.sku) AS sku,
  c.unidades AS unidades_cliente,
  w.unidades AS unidades_wms,
  COALESCE(c.unidades, 0) - COALESCE(w.unidades, 0) AS diferencia
FROM cliente AS c
FULL OUTER JOIN wms AS w ON c.sku = w.sku
ORDER BY sku;
conciliacion.pyDatos de ejemplo
import pandas as pd

cliente = pd.DataFrame({
    "sku": ["SKU-101", "SKU-204", "SKU-318"],
    "unidades": [120, 40, 15],
})
wms = pd.DataFrame({
    "sku": ["SKU-101", "SKU-204", "SKU-422"],
    "unidades": [118, 40, 7],
})

cruce = cliente.merge(wms, on="sku", how="outer", suffixes=("_cliente", "_wms"))
cruce["diferencia"] = cruce["unidades_cliente"].fillna(0) - cruce["unidades_wms"].fillna(0)
Resultado ilustrativo de esa consulta, con los mismos datos falsos. Una diferencia positiva significa más unidades en el sistema del cliente; una negativa, más en el WMS.
SKU Cliente WMS Diferencia
SKU-101 120 118 2
SKU-204 40 40 0
SKU-318 15 — 15
SKU-422 — 7 −7

SKU-318 solo está en el cliente. SKU-422 solo está en el WMS. Un join interno los habría borrado de la lista.
